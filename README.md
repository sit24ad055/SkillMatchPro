
# SkillMatch Pro: Workforce Assignment System

SkillMatch Pro is a web application to match workers with the best tasks for their skills. It helps companies easily manage team assignments and increase productivity.

## Features
- Automatically matches workers to tasks using their skill profiles.
- Simple, clean web interface.
- Auto-generate assignments with one click.

## How to Run
1. Download or clone this repository.
2. Open index.html in your browser (for frontend only), OR
3. For fullstack: Run npm install in the project folder, then npm start.

## Technologies Used
- React
- Node.js
- JavaScript
- CSS
